# JIANT FM - Techno Family Fork

**Modified JIANT with six new techno-family genres**

## What Changed
- Replaced BROKEN, AFROBEAT, BOSSA, JAZZ, BOOM BAP, STEPPERS with TRIBE TEKNO, MENTAL TEKNO, ACID CORE, HARDTEKK, TEKNO, PSY TRANCE
- All original 43 genres preserved
- Added new recipes and playable presets for new genres
